# al-atlas-chemicals-website
Official trilingual (EN · FR · AR, RTL) static website for AL ATLAS CHEMICALS TRADING L.L.C.

- Static: `index.html` + `assets/`. No build step, no backend, no cookies.
- Quotation form composes an email or WhatsApp message; nothing is stored.
- Photos: Unsplash licence (free commercial use, no attribution required). Credits: Maksym Kaharlytskyi (refinery), Shaah Shahidh (tanker), Serzill Hasan (terminal), Kenneth Berrios Alvarez (granules), Ricardo Gomez Angel (pipework), Rana Kaname (port), Robert Bock (Dubai), Ahmed Aldaie (Sharjah), Heyzeus Escribo (wheat), Zemos (warehouse), Jason Leung (drums).
- Deploy: OVH web hosting, Git integration on `main` → `www`.
